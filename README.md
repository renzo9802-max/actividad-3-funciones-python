# Actividad 3 — Proyecto colaborativo: funciones básicas de Python

## Descripción
Este repositorio contiene un tutorial introductorio de 30 funciones y herramientas integradas de Python. Cada tema presenta su utilidad, sintaxis y un ejemplo práctico relacionado con datos, producción e inventario.

## Objetivo
Investigar y documentar funciones básicas de Python mediante Jupyter Notebooks, y practicar el trabajo colaborativo usando GitHub.

## Integrantes y responsabilidades
- **Integrante 1: Renzo Pinilla** — preparar, ejecutar y revisar las primeras 15 funciones en `_Funciones1.ipynb`.
- **Integrante 2: Maria Ortiz** — preparar, ejecutar y revisar las 15 funciones complementarias en `_Funciones2.ipynb`.

## Contenido del repositorio
- `01_Funciones_basicas_1.ipynb`: primera parte del tutorial.
- `02_Funciones_basicas_2.ipynb`: segunda parte del tutorial.
- `README.md`: descripción e instrucciones del proyecto.
- `Informe_de_proceso.pdf`: informe final de la colaboración (subir cuando esté terminado).

## Funciones documentadas
**Parte 1:** `print()`, `input()`, `type()`, `int()`, `float()`, `str()`, `bool()`, `len()`, `range()`, `enumerate()`, `abs()`, `round()`, `sum()`, `min()` y `max()`.

**Parte 2:** `pow()`, `divmod()`, `sorted()`, `reversed()`, `all()`, `any()`, `isinstance()`, `zip()`, `map()`, `filter()`, `format()`, `repr()`, `bin()`, `hex()` y `ord()`.

## Cómo ejecutar los notebooks
1. Abre [Google Colab](https://colab.research.google.com/).
2. Selecciona **Archivo → Subir cuaderno** y elige el archivo `.ipynb` descargado desde este repositorio.
3. Ejecuta las celdas en orden y verifica los resultados.
4. En el ejemplo de `input()`, escribe el nombre de un cultivo (por ejemplo, `Lechuga`) y presiona Enter.
5. Guarda y descarga la versión final en formato `.ipynb`.
